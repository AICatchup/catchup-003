# 第3回の資料・活用事例

1件につき1つのMarkdownファイルで、作者、元資料、何をしたかを残します。スライド・記事・コード・デモが別の場所にあっても、その公開URLを紹介できます。

[投稿テンプレート](https://github.com/AICatchup/community/blob/main/templates/contribution.md) / [投稿方法](https://github.com/AICatchup/community/blob/main/CONTRIBUTING.md) / [フォームで投稿する](https://github.com/AICatchup/catchup-003/issues/new?template=share.yml)

運営がフォームから取り込む場合は、元Issueへのリンクを添えます。各ファイルから原典と作者をたどってください。
